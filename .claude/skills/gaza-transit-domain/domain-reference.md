# Gaza Transit Domain Reference

## Transit Arteries & Corridors
* **Salah al-Din Road (شارع صلاح الدين)**: Primary inland spine traversing north to south across Beit Hanoun, Gaza City, Deir al-Balah, Khan Yunis, and Rafah.
* **Al-Rashid Coastal Road (شارع الرشيد الساحلي)**: Western highway parallel to the Mediterranean coastline.
* **Key Connector Cross Streets**: Connecting Al-Rashid to Salah al-Din (e.g., Al-Bahr Street, Netzarim junction/Al-Shuhada, Al-Bi'ah Street).

## Palestinian Arabic Glossary
| Concept | Palestinian Arabic Term | Usage Notes |
|---|---|---|
| Cart-towing transit vehicle | عجلة (Ajala) | Predominant vehicle type in Gaza |
| Shared ride / commute | مشوار / خط | Standard public line |
| Special private trip | طلب خاص | Custom ride posted by rider |
| Route / Line | خط سير | The ordered stops list |
| Stop / Station | موقف / محطة | Designated boarding point |
| Fare | أجرة (شيكل) | In shekels (ILS) |
| Book a seat | احجز مقعد | Direct action CTA |

## Privacy & Safety Matrix
| User Role | Phone Visibility | Location Tracking | Retention Rule |
|---|---|---|---|
| **Driver** | Public on active offers/trips | Active while driving route | Purged when route ends |
| **Rider** | Hidden until booking confirmed | On-demand opt-in only | Immediate purge on trip end |
