# Ship Safely Workflow Reference

## Pull Request Template Structure
```markdown
## What a user can now do
- [Describe the newly unlocked user capability in plain words]

## What was cut / deferred
- [Explicitly list any omitted sub-features or future scope]

## How to see it
- [Exact steps to navigate, test, and visually inspect the change]
```

## Milestone Merge Checklist
1. [ ] Branch created from latest `main`.
2. [ ] All local tests pass (`npm test`).
3. [ ] Pull request opened with the three-part description.
4. [ ] Fleet QA runner comment received with passing status (`fleet-qa`).
5. [ ] Phone-sized screenshots reviewed for visual defects.
6. [ ] Ahmed confirms with explicit instruction to merge.
